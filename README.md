# CeibaCircular - Plataforma de Economía Circular TI

Plataforma de Economía Circular TI, GreenOps y Simbiosis Académica para **Ceiba Software** en alianza con la **Universidad Cooperativa de Colombia - Campus Pasto**.

## Inicio Rápido

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Módulos

1. **Dashboard Ejecutivo** - KPIs de impacto circular, gráficas de emisiones y widget biocentrista
2. **Inventario Circular** - Tabla de activos TI con ecoetiquetaje y pasaporte digital de minerales
3. **Ciclo de Vida & R's** - Kanban de estados, estrategias R, borrado NIST 800-88 y disposición RAEE
4. **Calculadora GreenOps** - Simulador interactivo de huella de carbono cloud y trabajo remoto
5. **Simbiosis Académica** - Portal de donación de equipos a instituciones educativas de Nariño

## Stack Tecnológico

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS + Lucide React + Recharts
- Persistencia JSON con Server Actions (sin BD externa)
- Datos semilla precargados automáticamente al primer uso

## Conceptos Académicos Integrados

- Economía Circular y las R (Reutilizar, Reparar, Reciclar)
- Ciclo del Carbono y Cambio Climático
- Ciclo del Agua y Data Centers
- Recursos Naturales Renovables/Inagotables vs. No Renovables
- Saneamiento Ambiental y RAEE
- Biocentrismo y Soluciones Basadas en la Naturaleza
- Economía del Bien Común
- Compras Verdes y Ecoetiquetaje
